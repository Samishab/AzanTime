# حساس الحرارة لشاشة «نُور» (ESP32)

> الأمثلة هنا **لم تُجرَّب على جهاز فعلي** بعد. جرّبها وأخبرنا بالنتيجة.

## ما تحتاجه
- لوحة ESP32 ذات 30 دبوساً (DOIT DevKit V1 أو مشابهة) وكابل USB للبرمجة.
- حساس بثلاثة أسلاك: إمّا **DS18B20** (مسبار معدني بسلك أحمر وأسود وأصفر)، أو وحدة **DHT22/DHT11** (علبة صغيرة بثلاث أرجل).
- شاحن USB لتشغيل اللوحة بعد البرمجة، وشبكة واي فاي **2.4GHz** (لا تدعم ESP32 شبكة 5GHz).

## التوصيل (كله على نفس طرف اللوحة D4 = GPIO4)

| الحساس | سلك/رجل الحساس | يوصَّل بـ |
|---|---|---|
| DS18B20 | أحمر (VCC) | 3V3 |
| DS18B20 | أسود (GND) | GND |
| DS18B20 | أصفر (DATA) | D4 |
| DHT22/DHT11 | (+) أو VCC | 3V3 |
| DHT22/DHT11 | (-) أو GND | GND |
| DHT22/DHT11 | OUT أو DATA أو S | D4 |

مع DS18B20 السلكي: ضع **مقاومة 4.7 كيلو أوم** بين سلك DATA (الأصفر) وسلك 3V3. إن كان الحساس مركّباً على لوحة صغيرة بثلاث أرجل فالمقاومة موجودة عليها ولا تحتاجها. لا توصّل الحساس بـ 5V.

## البرمجة بـ Arduino IDE
1. ثبّت Arduino IDE من arduino.cc.
2. من File ← Preferences أضف في «Additional boards manager URLs»:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. من Tools ← Board ← Boards Manager ابحث عن **esp32** (Espressif) وثبّته.
4. من Tools ← Board اختر **ESP32 Dev Module** (أو DOIT ESP32 DEVKIT V1).
5. من Sketch ← Manage Libraries ثبّت المكتبات:
   - للـ DS18B20: **OneWire** و**DallasTemperature**.
   - للـ DHT: **DHT sensor library** (Adafruit) و**Adafruit Unified Sensor**.
6. افتح الملف المناسب من هذا المجلد: `esp32-ds18b20.ino` أو `esp32-dht.ino`، واكتب اسم الواي فاي وكلمته.
7. وصّل اللوحة بالكمبيوتر، واختر المنفذ من Tools ← Port، ثم اضغط Upload (السهم →).
   - إن بقيت الرسالة «Connecting…» اضغط مع الاستمرار زر **BOOT** على اللوحة حتى يبدأ الرفع.
   - إن لم يظهر منفذ فثبّت تعريف CP2102 أو CH340 بحسب شريحة لوحتك.
8. افتح Tools ← Serial Monitor (سرعة 115200) وانظر سطر `IP:` فيه العنوان، مثل `192.168.1.60`.

## الاختبار
افتح في متصفح الجوال (على نفس الشبكة): `http://192.168.1.60/temp` فتظهر `{"temperature":27.3}`. إن ظهر خطأ 503 فالحساس غير موصول جيداً.

## الربط بالشاشة
الإعدادات ← الحرارة:
- المصدر: **حساس على الشبكة (HTTP)**
- الرابط: `http://192.168.1.60/temp`
- مسار الرقم في JSON: `temperature`
- التحديث كل: 30 ثانية
- للمعايرة استخدم «معايرة (± درجة)».

## نصائح
- ثبّت عنوان اللوحة من إعدادات الراوتر (حجز DHCP للوحة) أو بإزالة التعليق عن سطري `WiFi.config` في الملف، حتى لا يتغير الرابط بعد انقطاع الكهرباء.
- ضع الحساس بعيداً عن ظهر التلفاز الساخن وعن الشمس المباشرة، وإلا ظهرت قراءة أعلى من الحقيقية.
